# Volunteer-Availability-System
Web-based volunteer availability management system with role-based access, Supabase database integration, email integration, and automated scheduling workflows.


Problem: Organization needed a simpler way to collect and manage volunteer availability.

Initial solution: Web application using JavaScript, Supabase, and FullCalendar.

Features: Authentication, role-based access, availability management, admin view.

Process improvement: After stakeholder feedback, redesigned the workflow using Google Forms and Apps Script.

Technologies: JavaScript, HTML, CSS, Supabase, FullCalendar, Google Apps Script, Google Sheets, email.js.
